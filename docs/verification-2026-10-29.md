# 2026-10-29 Bevy 重构验证记录

代码已切换到 Bevy 网页运行时；原程序完整 GUI 对照仍未完成，因此整体原版一致性验收尚未通过。本记录区分规则、素材、浏览器和原程序证据。

## 已实现的切换

- `virtual-life-core` 提供纯 Rust 规则、解释器、随机流和严格存档；`virtual-life-app` 管理有序 Bevy 更新、原版场景、输入、像素、声音及资源；`virtual-life-web` 提供 WASM 入口和浏览器服务。
- 删除旧 TypeScript 游戏界面、Worker、手写渲染与独立动画循环。网页保留引导、画布、IME、文件、存储、缓存、全屏和媒体解码适配。
- 保持 WebGPU、640×480、4:3、最近邻及 `/VirtualLife/`。保存格式为 `virtual-life-bevy-save` v1，数据库为 `virtual-life-bevy`，不读取、迁移、导出或删除旧数据库。
- 补齐原建角、商店、职业、学校、成长分配、N1 对白/选择、关系输入、奖励跳过、音量拖动和片尾分支。修复 GDI 索引映射、透明键顺序、FLIC 裁剪、首次资源加载丢点击、过期异步结果和界面声音暂停。
- 实时时钟采用毫秒端点差，保留帧驱动更新，避免逐帧舍弃小数造成累计偏慢；后台、加载和恢复首帧不追赶时间。结局选择“结束人生”和恢复已结束存档均回主菜单，保留完成状态。

版本以 [官方稳定版冻结快照](dependencies-snapshot.json) 为准；[依赖说明](dependencies.md) 记录上游约束例外。Bevy 为 0.20.1，TypeScript 为 7.0.2，Rust 为 1.99.1，Node LTS 为 26.13.0，pnpm 为 12.16.1，绑定 CLI 与库均为 0.2.129。

Windows 和 Linux 均完成干净目录的 frozen npm 依赖安装。两套锁文件及精确声明通过核对；Linux 安装前后锁文件未变化。Linux 使用隔离的精确 Rust 工具链，从源码生成生产 WASM，随后执行原 Vite 配置和实际产物校验。

Windows 使用本机工具链；Linux 实测为 Ubuntu 26.04.1 WSL，CI 配置为 Ubuntu 24.04。远端 GitHub Actions 尚未执行。构建源码快照及逐字哈希核对保存在本地 `output/linux-repro/`，不声称跨操作系统二进制逐字相同。

## 尚未满足的验收门槛

- 原 EXE 固定 SHA-256 为 `e725c9c7dd9de766cd1bf66dba18260858e447980c65efbd292a9cd3687ef4c0`。当前 Windows 环境在启动时缺少 IV50/Indeo 解码器，并在 `0x451b62` 崩溃；临时安装元数据已自动恢复。没有取得可接受的原游戏完整画面。
- `tests/fixtures/original-visual-reference.json` 明确为 `acceptedAsVisualBaseline=false`。错误窗口、调试器截图、现代 GDI 字形和新客户端截图均不替代缺失的原程序 GUI 基准。
- 影片逐帧无损验证证明 FFmpeg 解码后的 YUV444 帧保持一致，浏览器像素断言证明 WebM 解码后到 Bevy 合成的结果；历史 IV50 的颜色转换仍需单独原机对照。
- Windows Chromium 156.0.8078.4 在本环境未取得 WebGPU 适配器，补充 Vulkan 和 ANGLE 软件参数探测后仍返回空适配器或超时，未将其计为网页测试通过；本地探测证据为 `D:/Temp/bevy-windows-webgpu-probe.json`。网页画面由 Linux 软件 WebGPU 实测；触控横竖屏为浏览器模拟，Android/iPhone/iPad 真机与真实硬件 GPU 尚未验收。
- 没有提交、推送或发布到 GitHub Pages；线上现有版本不代表本地 Bevy 产物。

原始未定义行为继续按 [保真边界](fidelity.md) 保留。最终验收需补齐缺少的原版场景、字体、时序和设备基准。
